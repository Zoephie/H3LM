# H3LM
GPU lightmapper for the Halo 3 and Halo 3: ODST MCC Editing Kits. Bakes the same lightmap tags as tool.exe, but on your graphics card with DirectX 12 ray tracing: minutes instead of hours, no tool.exe or farm, your PC stays usable. Less noise, fewer artefacts, sharper lightmaps and light across BSP seams. Free, Windows 10/11.
